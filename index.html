Cloud Computing Lab - Experiment 6

Static web app deployed on AWS Amplify from GitHub

About

This site is hosted on AWS Amplify. Every push to the main branch of this GitHub repository triggers a new build and deployment automatically.

Pipeline

  1. Code pushed to GitHub
  2. Amplify detects the commit
  3. Amplify builds and deploys the site
  4. Site is served over HTTPS
